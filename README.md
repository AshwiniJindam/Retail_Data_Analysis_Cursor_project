# Retail Data Analysis Project

## 📊 Overview

This is an end-to-end data analytics portfolio project that analyzes e-commerce/retail data to derive actionable business insights. Built using **Cursor AI** (AI-powered code editor), this project demonstrates modern data analytics workflow from raw data to interactive dashboard.

## 🎯 Project Goals

- Perform **Exploratory Data Analysis (EDA)** & data cleaning on an e-commerce dataset
- Conduct deep-dive analysis providing business insights based on:
  - Sales analysis
  - Geographic analysis  
  - Product performance
- Implement **Customer Segmentation using RFM Analysis** (Recency, Frequency, Monetary)
- Build an interactive **Streamlit dashboard** (2-page) with:
  - Business overview page
  - Customer lookup tool

## 🔍 Key Analysis Performed

### 1. Data Cleaning & Preprocessing
- Handled missing values
- Removed duplicate transactions
- Created derived columns (e.g., total_cost, invoice_date components)
- Data type conversions

### 2. Exploratory Data Analysis (EDA)
- Sales trends over time
- Revenue distribution
- Product category performance
- Customer purchase patterns

### 3. Sales Analysis
- Total revenue calculation
- Sales by month/period
- Top-selling products
- Revenue by country/region

### 4. Geographic Analysis
- Sales by country
- Customer distribution globally
- Regional performance comparison

### 5. Product Performance
- Top products by revenue
- Product category analysis
- Profit margins by product
- Best-selling items

### 6. Customer Segmentation (RFM Analysis)
- **Recency**: How recently did customers purchase?
- **Frequency**: How often do they purchase?
- **Monetary**: How much do they spend?
- Segmented customers into distinct groups for targeted marketing

## 📈 Key Insights & Deliverables

✅ Comprehensive data cleaning and preprocessing workflow  
✅ Sales performance metrics and trends  
✅ Geographic insights showing regional differences  
✅ Product performance analysis identifying top performers  
✅ Customer segmentation for targeted marketing strategies  
✅ Interactive 2-page Streamlit dashboard
